## Scope and result

The entire PDF was rendered, its text extracted, and all pages visually inventoried. Named elevations and sections were inspected at enlarged resolution. This is a source audit and reconstruction, not a completed as-built certification. All readable source statements are preserved in the page register. Rooms and construction elements that cannot be verified from the compressed presentation remain explicitly unresolved.

The earlier 2023 approximate viewer is superseded by a meters-based model using the final 2024 layout. Street and parking context uses the architect’s actual overhead rendering. The basement, upper mezzanine, future second-floor office shell, and roof have been added. No unavailable basement or future-office partition layout has been invented.

## Scale

One scene unit equals one meter. The visible clinic rectangle on page 12 is calibrated to the 3,254 sq ft clinic program area on page 14. This produces 15.15587864 source pixels per meter. That calibration assumes the stated program area corresponds to the traced clinic perimeter; the document does not resolve net/gross boundary conventions. It is not a surveyed length calibration, and no dimensional tolerance is claimed.

## Element-level inventory

Every wall segment has an ID, endpoints in meters, inferred thickness/height and source pages. Every furniture/equipment instance has an ID, reusable asset reference, position, rotation, scale, room association where identifiable, and status. Facade pieces and landscape battens are also stored as separate data elements. These are auditable reconstruction elements; their presence does not mean every real construction line or hidden item is documented.

## Reuse and interchange

The current model is `public/models/seen-alhambra-2024.json`, schema 2.0, SI units. No site coordinates belong in the generic renderer. Change facility data to replace a building, change an asset definition to replace all uses, or edit one object transform to change a specific placement. Source imagery travels separately at its declared paths. GLB exports are in meters and assemble the full building independent of the current exploded/cutaway view.

## Validation limits

Checks cover schema/JSON round trips, reference links, known area arithmetic, triangulation, nonzero wall geometry, model assembly, visibility/level transformations and portable object geometry. Browser visual and interaction testing has not been performed. The PDF does not support claiming pixel-perfect as-built accuracy yet.
